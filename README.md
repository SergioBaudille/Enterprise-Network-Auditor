Enterprise Network Auditor is a PowerShell-based network auditing and troubleshooting tool designed to help IT Support, Help Desk and System Administrators quickly validate network connectivity and identify common infrastructure issues.

Features
Host Connectivity Testing
DNS Resolution Validation
Default Gateway Verification
Common Port Scanning
Report Generation
Interactive PowerShell Menu
Tested Ports
Port	Service
53	DNS
80	HTTP
443	HTTPS
445	SMB
3389	RDP
Technologies Used
PowerShell
Test-Connection
Test-NetConnection
Resolve-DnsName
Get-NetRoute
Object-Based Reporting
Example Use Cases
Network troubleshooting
Connectivity validation
DNS diagnostics
Service availability checks
Help Desk troubleshooting
