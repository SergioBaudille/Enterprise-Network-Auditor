# Enterprise Network Auditor | PowerShell

Enterprise Network Auditor is a PowerShell-based network auditing and troubleshooting tool designed to verify network connectivity and diagnose common infrastructure issues.

## Features

- Host Connectivity Testing
- DNS Resolution Validation
- Default Gateway Verification
- Port Scanning
- Report Generation

## Ports Tested

- 53 (DNS)
- 80 (HTTP)
- 443 (HTTPS)
- 445 (SMB)
- 3389 (RDP)

## Technologies Used

- PowerShell
- Test-Connection
- Resolve-DnsName
- Test-NetConnection
- Get-NetRoute
